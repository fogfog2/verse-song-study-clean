# 가사 공개 노출 점검 — 2026-10-13

## 발견 사항

- 기존 저장소가 public이며 GitHub Pages가 활성화되어 있었습니다.
- 현재 커밋은 원문 대신 암호화 파일을 사용하지만 이전 기록에는 학습 자료가 남아 있었습니다.
- `public/study.encrypted.json`은 암호와 관계없이 다운로드할 수 있는 배포 자산이었습니다.
- 개발 및 미리보기 명령이 모든 네트워크 인터페이스에 바인딩되어 있었습니다.

## 조치

- 기존 저장소를 private로 변경하고 Pages를 삭제했습니다. Actions도 비활성화했습니다.
- 확인 시점에 기존 저장소의 fork, release, Actions artifact 및 실행 중 작업 수는 모두 0이었습니다.
- 암호화 자료를 Git 추적에서 제외하고 `.private/`로 이동했습니다. 원본과 암호는 유지했습니다.
- 개발 서버만 로컬 암호화 파일을 제공하며 배포 빌드에는 포함하지 않습니다.
- 개발·미리보기 기본 바인딩을 loopback으로 변경하고 민감한 디렉터리 직접 접근을 차단했습니다.
- 자동 Pages 배포를 제거하고 콘텐츠 검사와 테스트·빌드만 실행하는 CI로 교체했습니다.
- 신규 비공개 코드 저장소는 현재 코드만 복사한 하나의 초기 커밋으로 시작하며 과거 Git 객체를 복사하지 않습니다.

## 검증 범위와 남는 한계

원본의 25자 이상 영어 구절 249개를 현재 추적 파일과 비교했을 때 일치 본문이 발견되지 않았습니다. 단순 문자열 비교이므로 모든 변형이나 짧은 인용을 검증하는 것은 아닙니다. 타이밍 문서의 불필요한 원문 예시도 제거했습니다.

기존 비공개 저장소와 기존 PC의 `.git`에는 복구를 위해 과거 기록이 남습니다. 제3자가 이전에 저장한 복제본, 검색 캐시, 다운로드 사본은 이 조치로 회수되지 않습니다. 개인 편집 자료는 브라우저 localStorage에 평문 저장되므로 화면의 잠금 기능을 저장소 암호화로 간주하면 안 됩니다.
